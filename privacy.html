ringkasan singkat

katakatla adalah game tebak kata 5 huruf gratis yang dibuat oleh Anas. kami percaya transparansi soal data, jadi ini ringkasannya:

  • kami simpan: username yang kamu pilih, ID anonim, dan riwayat tebakan kamu di game
  • kami tidak simpan: nama asli, email, lokasi, atau data pribadi lainnya
  • kami tidak jual data kamu ke siapa pun
  • kami tidak pasang iklan atau tracking pihak ketiga

data yang kami kumpulkan

saat kamu main katakatla, kami menyimpan informasi berikut:

  • username — yang kamu pilih sendiri saat pertama kali main
  • ID pengguna anonim — kode unik (UUID) yang otomatis dibuat sistem, tidak terhubung ke identitas asli kamu
  • data permainan — kata yang kamu tebak, jumlah percobaan, durasi main, hasil (menang/kalah), tanggal main
  • statistik — total skor, win rate, streak, distribusi tebakan

kami tidak meminta atau menyimpan: alamat email, nomor telepon, lokasi, foto, atau informasi pribadi lainnya.

tujuan pengumpulan data

data di atas dipakai khusus untuk:

  • menjalankan game (nyimpen progress kamu, generate kata harian)
  • menampilkan leaderboard harian, mingguan, dan bulanan
  • menampilkan statistik personal kamu di halaman stats
  • mencegah kecurangan (anti-cheat, validasi durasi tidak wajar)

cookies dan localStorage

katakatla menggunakan localStorage di browser kamu untuk menyimpan progress permainan harian (tebakan kamu yang belum selesai). ini bukan cookie tracking — datanya cuma ada di browser kamu sendiri dan tidak dikirim ke server kami untuk dilacak.

kami tidak menggunakan cookie pelacakan, Google Analytics, Facebook Pixel, atau tracker pihak ketiga lainnya.

pihak ketiga yang kami pakai

katakatla berjalan dengan bantuan dua layanan pihak ketiga:

  • Supabase — untuk menyimpan data game (username, attempts, dst.). Supabase patuh pada standar GDPR. kebijakan privasi Supabase
  • Vercel — untuk hosting website. Vercel mungkin mencatat log akses standar (IP, browser, waktu kunjungan) untuk keperluan teknis. kebijakan privasi Vercel

kami tidak memiliki kontrol langsung atas data yang dikumpulkan oleh kedua layanan ini, tapi kami memilih mereka karena reputasi keamanan dan kepatuhan privasi.

hak kamu sebagai pengguna

sesuai dengan UU Perlindungan Data Pribadi (UU 27/2022) Indonesia, kamu punya hak untuk:

  • akses — minta lihat data apa aja yang kami simpan tentang kamu
  • perbaikan — minta data yang salah diperbaiki (misal: ganti username via halaman stats)
  • penghapusan — minta semua data kamu dihapus dari database kami
  • penolakan — berhenti main kapan aja, tanpa konsekuensi

untuk menggunakan hak-hak ini, hubungi kami via email di bagian bawah halaman ini.

anak di bawah umur

katakatla cocok dimainkan oleh segala usia. kami tidak meminta data identitas pribadi, jadi tidak ada risiko khusus untuk anak-anak. tapi kami sarankan orang tua untuk mendampingi anak yang main game online.

keamanan data

kami menggunakan enkripsi standar industri (HTTPS) untuk semua koneksi, dan database kami dilindungi dengan Row Level Security (RLS) Supabase. tapi tidak ada sistem yang 100% aman — jika kamu mencurigai ada masalah keamanan, segera kontak kami.

perubahan kebijakan

jika ada perubahan kebijakan privasi, akan diumumkan di halaman ini dengan update tanggal di atas. lanjut main berarti kamu setuju dengan versi terbaru.
