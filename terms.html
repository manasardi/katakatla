selamat datang di katakatla

dengan main katakatla, kamu setuju dengan syarat-syarat di bawah ini. kalau kamu tidak setuju, silakan tidak main game ini. simple aja.

1. tentang katakatla

katakatla adalah game tebak kata 5 huruf berbahasa Indonesia, terinspirasi dari Wordle. game ini:

  • gratis — tanpa biaya, tanpa langganan
  • tanpa iklan — kamu nggak akan dikejar iklan saat main
  • independen — dibuat oleh satu orang (Anas), bukan perusahaan
  • open source — kode tersedia di GitHub dengan lisensi MIT

2. hak penggunaan

kamu boleh:

  • main katakatla kapan aja, sebanyak yang tersedia per hari
  • share hasil tebakan kamu ke teman atau social media
  • memberi feedback atau saran (sangat dihargai!)

3. perilaku yang diharapkan

untuk menjaga komunitas katakatla nyaman, kamu tidak boleh:

  • menggunakan username yang mengandung kata kasar, SARA, atau menyinggung
  • menggunakan username yang menyamar sebagai orang lain (impersonation)
  • melakukan kecurangan dengan automation/bot/script untuk farming skor
  • mencoba meretas, mengganggu, atau merusak sistem game
  • mengeksploitasi bug untuk keuntungan di leaderboard

kalau kami nemu pelanggaran, kami berhak:

  • mengubah atau menghapus username kamu
  • menghapus skor dari leaderboard
  • memblokir akses kamu ke game (kasus ekstrim)

4. hak kekayaan intelektual

nama "katakatla", logo, design game, dan kode adalah milik Anas (dengan kode di-lisensikan MIT). kamu boleh main, tapi tidak boleh:

  • mengklaim game ini sebagai karya kamu
  • menjual atau mengkomersialisasikan tanpa izin
  • membuat copy persis dengan branding yang sama

kalau kamu mau bikin game serupa berbasis kode kami, silakan fork dari GitHub dengan tetap mematuhi lisensi MIT (kasih atribusi).

5. konten kamu

username yang kamu pilih dan tebakan kamu adalah milik kamu. tapi dengan main katakatla, kamu memberi izin pada kami untuk:

  • menampilkan username kamu di leaderboard publik
  • menyimpan riwayat tebakan untuk perhitungan statistik dan streak

kalau kamu mau username/data kamu dihapus, hubungi kami (lihat kebijakan privasi).

6. ketersediaan layanan

katakatla disediakan "as-is" alias apa adanya. kami berusaha menjaga game tetap online, tapi:

  • tidak ada jaminan uptime 100% — bisa aja maintenance atau ada bug
  • fitur bisa berubah, ditambah, atau dihapus tanpa pemberitahuan
  • kalau game offline atau bermasalah, mohon kesabarannya — ini project pribadi

7. batasan tanggung jawab

katakatla adalah game hiburan. kami tidak bertanggung jawab atas:

  • kehilangan progress karena bug, browser crash, atau localStorage terhapus
  • dampak emosional dari kalah/menang (kami harap kamu fun!)
  • perubahan ranking di leaderboard karena reset atau koreksi data

8. perubahan syarat

syarat penggunaan ini bisa berubah seiring waktu. perubahan akan diumumkan di halaman ini dengan update tanggal di atas. lanjut main berarti kamu setuju dengan versi terbaru.

9. hukum yang berlaku

syarat ini diatur berdasarkan hukum Republik Indonesia. kalau ada sengketa yang nggak bisa diselesaikan secara baik-baik, akan diselesaikan di pengadilan yang berwenang di Indonesia.
